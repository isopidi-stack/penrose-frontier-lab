$$\nabla_\mu Z^\alpha = \partial_\mu Z^\alpha + \mathcal{A}_\mu{}^\alpha{}_\beta Z^\beta$$

3. **Rest-Mass Integration:** Investigating symmetry-breaking conformal invariants and central-charge projections for massive fermion fields.
